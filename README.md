# HCHL_Week-2
For this week, I decided to make a 3d printer as a desk toy. It also has a pen plotter attachment that holds a pencil, but other than that (_it is completely useless_) makes for good desk decor. The individual STEP files are posted, and the complete STEP file has everything laid out.

Everything is modeled in Onshape; the tolerances should work for any printer, and everything should be able to print without supports.
